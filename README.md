\# Smart Inventory \& Billing System



A Python-based inventory and billing application built with Python,

PostgreSQL, OOP and Streamlit.



This project manages products, customers, orders and billing while

providing inventory information and reports through a Streamlit dashboard.



\## Tech Stack



\- Python

\- PostgreSQL

\- SQL

\- OOP

\- Streamlit

\- Pandas

\- Matplotlib

\- Git \& GitHub



\## Project Structure



| File | Purpose |

|---|---|

| `app.py` | Streamlit UI and application flow |

| `database.py` | PostgreSQL connection and database operations |

| `reports.py` | Reports and analytics |

| `requirements.txt` | Python dependencies |

| `.gitignore` | Files excluded from Git |

| `sql/SmartInventory\_schema.sql` | Database schema |



\## Database



PostgreSQL is used as the backend database.



Main entities:



\- Customers

\- Products

\- Orders

\- Order Items



\## How the Application Works



The user interacts with the Streamlit interface.



The application sends requests through the Python/OOP logic to the

database layer, where data is stored and retrieved from PostgreSQL.



Reports and inventory information are then displayed through the dashboard.





\## Features



\- Product and inventory management

\- Customer management

\- Order and billing management

\- PostgreSQL database integration

\- Low-stock monitoring

\- Inventory information

\- Sales and purchase reports

\- Interactive Streamlit dashboard

\- Database-driven analytics
